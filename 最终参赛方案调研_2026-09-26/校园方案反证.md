# 对「누락제로：申请材料核验与补件 Agent」的独立反证

核查日期：2026-09-26。目的：判断上一轮默认校园方案是否足以作为一般部冲击大奖的唯一推荐。本笔记是竞争力判断，不是官方评分或获奖概率。只做调研，未实现参赛代码、未测试竞品账号、未联系潜在用户。

## 结论

**应撤回“因为资料齐、八天容易完成，所以最适合冲第一”的强默认。** 这些因素支持交付可行性，不能单独支持大奖竞争力。原方案的主体——读取韩文资料、提取要求、追问缺件、输出文件——已经接近通用桌面 Agent 加文档工具的常规能力。

不必因有竞品而直接放弃；本届不是学术算法首创比赛。但如果没有独立流程核验者、没有未见公告上的比较实验、没有可观察的错误阻断优势，它更适合作为可靠完成比赛的备选，而非有证据支撑的唯一冲奖方案。

最有力的评委质疑是：**“把相同文件交给通用 Agent，并告诉它核对后打包，为什么做不到同样的事情？”** 目前旧方案没有实测答案。

## 六个足以削弱竞争力的缺口

1. **把可交付当成技术差异。** ZIP 是输出容器，生成 ZIP 不证明 Agent 比脚本可靠。必须检查最终包语义是否满足适用要求。
2. **把真实公开公告当成真实用户验证。** 公告真实，只能证明来源真实；人工构造的缺件包仍是仿真案例。真实降低退件率需要实际受理结果，八天内很难获得。
3. **用本比赛的已知陷阱做演示，会显得硬编码。** 博士组别、旧表缺开发计划、正午截止，已经被研究人员知道。若只演这些，无法展示泛化。
4. **来源“更新”不等于效力“更新”。** 学校对内部支持的限制、全省比赛的资格、附件修订时间可能各有适用范围。“最新文件覆盖旧文件”可能制造新错误。
5. **签名与证明核验容易越界。** 能判断文件存在、可读字段或有无可见签名痕迹，不能证明签名真实、证件有效或资格必然通过；状态必须保留人工复核。
6. **八天同时支持三类申请、双语、HWP 编辑和完整门户，可能牺牲最关键的实验。** 原方案对“真实用户可得”的判断还没有人员确认。

这些是对拟议设计的分析判断；不表示本届评委一定会这样提问，也不表示博士参赛必须采用复杂模型。

## 如果保留，最小改造应是什么

将产品焦点缩为：**“规则发生变化后，防止申请包继续被错误标记为可提交的核验 Agent。”** 用户价值是降低版本、适用条件和证据不一致造成的错误放行。文档阅读、问答、模板和压缩包是配套能力，不再是主标题。

拟实现四个关键步骤：

1. 将要求编成可检查记录：发布机关、原文位置、适用人群、生效时间、待满足事实、证据文件、状态。
2. 模型把自然语言例外转为候选检查条件；程序执行文件、字段、日期等可确定检查；语义冲突保留“不确定”，不能自行编造裁决。
3. 新公告或新材料进入后，使受影响的原通过结论失效，重新追问或检查，而不是只追加一段摘要。
4. 只有完成相应检查后，才生成带版本清单与待复核事项的文件包；解包回读验证实际内容。

**这不是算法首创声明。** 来源记录、状态管理和变更检查都是已有思路；拟参赛新增部分是对一条具体申请流程的实现及可靠性证据。若没有实测优势，换成“证据图谱”“多 Agent”或“可信 AI”等名称不会增强作品。

## 能否保留为主选题的验证门槛

以下是建议的决策门槛，不是已取得成果：

- 9 月 28 日前能找到一位熟悉该申请流程、愿意独立核验答案的人，以及 5–8 位自愿试用者。无需把一般同学的意见包装为行政机关认证。
- 至少有一个主流程和一个保留流程；后者全部资料在系统提示和规则设计完成后才交给开发者运行。不能把同一公告改几处数字称为跨流程泛化。
- 正式开发开始后，用同一模型、同一解析结果、同一工具权限与大致调用预算比较：良好提示的通用 Agent、确定性检查工具、拟议系统。通用 Agent 应获合理调试机会，不能故意设置弱基线。
- 30–50 个小规模测试覆盖正常、缺件、身份分支、未来生效、机关范围不同、附件修改、工具失败；由核验者预先定答案。真实案例和人工变体分开报告。
- 同时报告错误放行率、有效材料误拦率、最终包正确率、未知状态比例和耗时。不能通过“全部拒绝/全部转人工”换取表面的零错误。
- 使用公平的对照实验后，如果拟议机制没有降低错误或处理时间，应该如实缩小主张。不要挑选通用 Agent 偶发失败的截图作为全部证据。

只要前两项资源仍未确认，我不建议继续把这个校园方向称为最终冲第一方案。若主方向另选制造或其他领域，本笔记也提供一条通用审查准则：**核心卖点必须经得住“成熟工具已经能做什么”和“你的新增机制实际多解决了什么”这两问。**

## 研究边界

本次来源均为提供商官网、官方帮助或作者仓库，证明的是“对方公开提供/宣传哪些能力”，不是独立性能测评。未看到竞品完整内部功能，不据此断言市场空白。未获知本届正式评分权重及参赛阵容，因此不计算或承诺夺冠概率。
