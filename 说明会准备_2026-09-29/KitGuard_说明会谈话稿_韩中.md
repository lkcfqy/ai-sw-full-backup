## 约20秒的简短介绍

안녕하세요, 교수님. 저희는 인공지능융합공학과 해피 팀입니다. 프로젝트 이름은 키트가드입니다. 주문에 맞게 부품을 준비했는지 확인하는 AI 에이전트입니다. 주문이 바뀌거나 사진만으로 확인하기 어려울 때 다시 확인하도록 안내하고, 사진과 검사 기록을 함께 남기는 것이 핵심입니다.

中文：老师您好，我们是人工智能融合工程专业的해피队，项目叫KitGuard。它是帮助检查零件是否按订单备齐的AI Agent。核心是在订单变化或照片不足以判断时，引导重新确认，并保留照片和检查记录。

## 约60—90秒的完整介绍

안녕하세요, 교수님. 저희는 국립창원대학교 인공지능융합공학과의 2인 팀, 해피입니다.

저희 프로젝트는 키트가드입니다. 작업자가 주문에 맞게 부품을 준비했는지 확인하는 AI 에이전트입니다.

예를 들어, 와셔가 두 개 필요한 주문이 세 개로 바뀌면, 이전 확인 결과를 그대로 쓰지 않고 바뀐 주문을 기준으로 다시 확인합니다.

사진에서 부품이 겹쳐 보여 수량을 확인하기 어려우면, 부품을 펼쳐 놓거나 다시 촬영하도록 안내합니다. 부족한 부품을 보충한 뒤에는 새 사진으로 다시 검사하고, 마지막에는 작업자가 실물을 확인합니다.

목표는 주문 변경으로 생기는 확인 오류를 줄이고, 사진과 검사 기록을 함께 남기는 것입니다.

우선 볼트, 너트, 와셔, L형 브래킷 네 종류의 부품을 사용하는 작은 실험으로 정확도와 사용성을 검증할 계획입니다.

이 범위가 대회 취지에 잘 맞는지, 어떤 검증을 우선하면 좋을지 조언을 부탁드립니다.

中文意思：

老师您好，我们是国立昌原大学人工智能融合工程专业的两人队해피。我们的项目叫KitGuard，是帮助操作者检查零件是否按订单备齐的AI Agent。

例如，订单原来需要两个垫圈，后来改成三个，系统就要按新订单重新检查。照片中的零件重叠、数量不清楚时，会引导操作者把零件分开放置或重新拍照。补齐缺少的零件后，用新照片复核，最后仍由操作者确认实物。

目标是减少订单变化造成的确认错误，同时保留照片和检查记录。我们计划先用螺栓、螺母、垫圈和L形角码四类零件做小规模实验，验证准确性和可用性。希望老师对项目范围和优先验证事项提出建议。

## 老师可能追问的回答

### 1．具体给谁用？为什么选这个场景？

**韩语**

목표 사용자는 주문에 따라 여러 종류의 부품을 한 세트로 준비하는 작업자입니다. 주문이 자주 바뀌는 소량·다품종 작업을 생각하고 있습니다. 먼저 저희가 직접 부품을 준비하고 정답을 확인할 수 있는 작은 실험부터 진행하려고 합니다.

**中文**：面向按订单配套零件的操作者，关注订单经常变化的小批量、多品种工作。先做我们能直接准备实物、核对正确答案的小规模实验。尚未确认工厂合作或正式部署。

### 2．系统具体怎样工作？

**韩语**

작업자가 주문을 입력하고, 사진에서 검사할 범위를 지정합니다. AI가 사진에 보이는 부품을 정리하면, 프로그램이 주문 수량과 비교합니다. 주문이나 검사 범위가 바뀌면 이전 확인 결과를 다시 사용하지 않도록 하고, 확인에 사용한 사진과 결과를 함께 기록합니다.

**中文**：人输入订单并指定照片中的检查范围；AI整理可见零件，程序计算数量并与订单比较。订单或范围变化后，旧核验结果失效，照片和结果一并记录。检查范围由人指定，不能说是AI自动定位全部目标。

### 3．为什么称为Agent？AI和普通程序分别做什么？

**韩语**

사진 분석 결과와 현재 주문 상태에 따라, 재촬영이나 부품 보충, 작업자 확인 같은 다음 단계를 안내하는 흐름입니다. 새로운 사진이 들어오면 다시 검사합니다. AI는 사진 관찰과 변경 지시 해석을 맡고, 수량 비교와 주문 버전 확인은 프로그램이 담당합니다.

**中文**：系统依据观察结果和当前订单，推进补拍、补件、人工确认，再用新证据复核。AI负责观察和理解，确定性的数量比较、版本与状态检查由程序完成。不要把所有规则分支都说成大模型自主规划。

### 4．与一般视觉检测、条码或清单有什么区别？

**韩语**

저희가 검증하려는 부분은 주문 변경, 불확실한 사진, 재확인 요청을 하나의 작업 흐름으로 연결하는 것입니다. 고정된 품목과 수량에서는 간단한 규칙 방식이 더 유리할 수 있어서, 수기 체크리스트와 규칙 방식도 비교하려고 합니다.

**中文**：要验证的价值是把订单变化、不完整的照片和重新确认连接起来。固定物料、固定数量时，简单规则可能更合适，所以也要和人工清单及规则方法比较。备料视觉检测已有商业方案，不声称全球首创。

### 5．这么少的零件，人工数不是更快吗？

**韩语**

단순히 몇 개를 세는 작업에서는 사람이 더 빠를 수 있습니다. 저희는 주문 변경을 반영하고, 누락을 확인하고, 기록을 남기는 과정에서 어떤 도움이 되는지 보려고 합니다. 실제 시간 절감 효과는 아직 확인하지 못했기 때문에 비교 실험이 필요합니다.

**中文**：单纯数几个零件，人工可能更快。需要检验的是处理订单变化、发现缺件和记录结果的整体价值。目前没有实测的节省时间结论。

### 6．用什么模型和设备？需要训练吗？

**韩语**

현재 구성은 MacBook Pro에서 Qwen3.6-27B의 4비트 양자화 모델을 MLX-VLM으로 실행하는 방식입니다. 별도 학습 없이 기존 모델을 활용합니다. 개발과 검증의 초점은 주문 관리, 사진 확인, 재검사와 기록을 연결하는 부분입니다.

**中文**：当前配置是在Mac上用MLX-VLM运行Qwen3.6-27B的4位量化模型，不重新训练模型。重点是任务流程、核验和记录。另一台RTX 3080电脑尚未验证同一模型运行，不宣称两机都已通过测试。

听到模型细节容易紧张时，可以只说：

공개 비전 언어 모델을 Mac에서 로컬로 실행하는 구성입니다. 모델을 새로 학습시키지는 않습니다.

中文：使用在Mac上本地运行的公开视觉语言模型，不重新训练模型。

### 7．数据哪里来？现在有真实效果吗？

**韩语**

공개 이미지는 기능 점검에 활용하고 있습니다. 실제 작업에 대한 검증은 저희가 직접 준비한 부품과 새로 촬영한 사진으로 진행할 계획입니다. 현재 실제 사용자를 대상으로 한 현장 검증 결과는 없습니다.

**中文**：公开图用于功能检查；计划用自行准备的实物和新照片开展验证。目前没有真实用户现场验证结果。公开照片真实，不等于已经完成真实操作或工厂验证。

### 8．怎么评估？准备做多大范围？

**韩语**

처음에는 부품 네 종류, 종류별 최대 세 개, 전체 열두 개 이하로 범위를 제한합니다. 정상, 누락, 배경 물체, 가림 등을 포함한 12개 사례부터 계획하고 있습니다. 사람이 확인한 정답과 비교해서 정답, 오답, 판단 보류와 실행 실패를 나누어 기록하려고 합니다.

**中文**：范围是四类部件、每类最多三个、总计不超过十二个；初步计划十二个案例，与人工真值比较，分别记录正确、错误、不确定和执行失败。这些是计划数量，不是已完成结果。

补充：第一轮固定照片试验只验证照片任务。若要证明整段工作更省时，需要另外记录摆放、拍照、补件、复核等全过程，并处理先后顺序造成的学习影响。

### 9．现在做到什么程度了？

**韩语**

현재 기본 프로토타입과 공개 이미지 평가 기록은 있습니다. 다만 실제 사용자의 작업 효과는 아직 검증하지 못했습니다. 기존 작업의 사용 가능 범위는 주최 측 기준을 확인하고, 허용되는 범위에 맞춰 진행하겠습니다.

**中文**：已有基本原型和公开图片评测记录，真实用户工作效果尚未验证。已有工作是否可以使用，需要按主办方规则确认。这个回答用于准确说明实际进度，不将已有原型说成“完全没有开发”，也不将公开图测试说成现场成绩。

### 10．两个人怎么分工？

**韩语**

팀장 남청청은 요구사항 정리, 사용자 검증과 제출 관리를 맡고, 팀원 이개심은 실물 데이터 준비, 평가와 시연 준비를 맡는 계획입니다. AI 코딩 도구도 활용하며, 최종 코드와 결과 검토는 저희 팀이 책임지겠습니다.

**中文**：按报名分工，队长负责需求、用户验证和提交管理；队员负责实物数据、评测和演示准备。使用AI开发辅助工具，团队负责最终审核与结果。
