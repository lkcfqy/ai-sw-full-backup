# 공개 사진으로 실제 사용자 검토 / 用公开照片做真实用户试用

이 문서는 선택 가능한 향후 시험 절차입니다. 작성만으로 참여자나 시험 결과가 생기지 않습니다. 현재 보관된 `DEMO-AUTOMATION` 및 `ENGINEERING-CODEX` 기록은 자동화 개발 점검이며 실제 사용자 수에 포함하지 않습니다.

本页是可选的后续试用方案，不是已经完成的用户研究。现有自动化审查记录不能算真实参与者。

## 한국어: 참여자 안내

목적은 사진·주문 버전·AI 판단을 사람이 이해하고 검토할 수 있는지 확인하는 것입니다. 실제 부품, 카메라, 공장 방문은 필요하지 않습니다. 개발자의 Mac에서 실행하거나, 화면을 공유하며 참여자가 실제 조작·판단을 하도록 합니다. 개발자가 대신 답을 선택한 경우 그 구간을 보조로 기록합니다.

1. 시험 목적과 기록 범위를 설명하고 참여 의사를 확인합니다. 이름·소속·전화번호 대신 P01 같은 코드를 사용합니다. 중단해도 불이익이 없습니다. 화면 녹화가 필요한 경우 별도로 동의를 구합니다.
2. 공개 사진 검토 페이지에서 `봉투 키트 · 주문 변경`을 선택합니다. 사진, 출처 및 요구 수량을 먼저 확인하고, 어떤 결과를 기대하는지 자기 말로 설명합니다.
3. 사진 검사를 실행합니다. 대기시간을 포함해 버튼 클릭부터 결과 표시까지 기록합니다. AI 수량과 주문 차이를 읽고 이해한 내용을 설명합니다. 정답을 먼저 알려주거나 동의를 유도하지 않습니다.
4. “볼트를 2개로 변경하고 나머지는 유지해 주세요.”를 입력합니다. 제안된 수량을 확인하고 실제로 의도한 변경일 때만 승인합니다. 이전 결과가 현재 주문에 계속 적용되는지 확인합니다.
5. 동일 공개 사진 재사용의 의미를 읽고 동의하면 새 버전에 등록합니다. 다시 검사한 뒤 본인의 결론과 근거를 디지털 검토에 기록합니다. AI에 동의하지 않거나 판단하기 어렵다고 답해도 정상적인 결과입니다.
6. 증거 ZIP을 내려받아 압축을 풀고 `OPEN_ME.html`을 엽니다. R1과 R2, 과거 기록과 현재 기록, 같은 사진의 재사용을 구분할 수 있는지 확인합니다.
7. 아래 질문에 본인의 말로 답합니다. 개발자의 평가문을 그대로 붙여 넣지 않습니다.

| 질문 | 기록할 내용 |
| --- | --- |
| 무엇을 확인하는 도구라고 이해했나요? | 참여자의 원문 답변 |
| 주문을 바꾼 뒤 어떤 기록이 무효가 되었나요? | 이해한 내용, 틀린 이해도 그대로 보존 |
| 결과가 불확실하거나 마음에 들지 않으면 무엇을 하겠나요? | 선택과 근거 |
| 가장 혼란스러운 화면이나 문구는 무엇인가요? | 화면/버튼과 개선 제안 |
| 실제 본인 업무에 사용할 상황이 있나요? | 있다면 상황; 없다면 없다고 기록 |

진행자가 남길 최소 기록: 날짜, 익명 코드, 사용한 제품 버전·모델 모드, 시작/종료 시각, 모델 대기시간, 실제 완료한 단계, 도움을 준 단계, 오류/중단, 원문 의견, 참가 동의 여부. 참여자의 동의 없이 녹화·연락처·불필요한 개인정보를 추가하지 않습니다.

## 中文：你需要实际做什么

可邀请至少3位不同的、愿意试用的真人，每人完成一次上面的公开照片流程。可以在你的电脑上操作，也可通过屏幕共享指导，由参与者本人做判断。无需购买零件；不要替他们填写“满意”“节省时间”等答案。3个匿名代码本身不能证明有3位不同参与者。真实机构反馈是赛事说明中的另一条路径，不必为了凑人数虚增参与者。

保存每人的原始意见、实际遇到的问题和对应工单/证据包，再记录根据意见做了哪些改进。参与者不满意、无法完成或中途退出也保留，不只收集好评。数字审查回执的 `user_validation:false` 不能手工改为 `true`；真实试用记录应作为单独、可核查的研究资料。

这只能支持“有人真实试用了数字资料审核流程”的陈述，不能推出识别准确率、工厂试点效果或节省人工时间。若要比较人工与AI效率，需要另行预先设计任务分配、顺序和计时边界，避免同一人先看过答案后重复操作。是否符合赛事用户反馈加分，仍由评委按实际材料判断。
