**목표와 구조.** 현재 BOM과 사진 근거에 맞는 부품 수량 판단을 제공하는, 고정 규칙으로 실행을 관리하는 Agent이다. 모델은 물체 목록과 불확실성을 만들고 프로그램은 수량·차이·현재 상태에 따라 다음 단계를 고른다. 자유로운 자율 계획이나 자동 출고 승인을 주장하지 않는다.

`사진·현재 BOM → 관찰 도구 → 수량/차이 규칙 → 추가 자료·수동 검토·디지털 의견 → 버전별 이력·증거 ZIP`

| 구성 | 실제 구현 |
|---|---|
| Goal | 현재 버전의 사진 자료와 요구 수량을 대조한다. bolt/nut/washer/bracket, 각0–3개·총1–12개이며 SKU·규격 검증은 제외한다. |
| Reasoning | 모델의 구조화된 물체 목록에서 프로그램이 수량을 계산한다. `null`은 미확정이며 0이나 기대 수량으로 바꾸지 않는다. 시각 모델에 BOM 목표 수량을 주지 않는다. |
| Tool | 로컬 원본·90도 회전 관찰, 두 관찰이 명확하게 일치할 때 nut/washer 후보의 국소 분류·형태 확인, 파일/상태 읽기·쓰기, BOM 비교와 증거 내보내기를 실행한다. |
| State / Feedback | 주문 버전·근거 세대·사진/범위·검사와 런타임을 결합한다. 변경 시 이전 검사를 무효화한다. 연속 불명확 상태에서 서로 다른 추가 사진 2장 후에도 불명확하면 수동 검토한다. 같은 사진은 새 근거로 세지 않는다. |
| Review | 공개 사진은 동의/추가 자료/이견/판단 불가 의견을 원래 AI 결과와 저장한다. 같은 사진 재사용은 명시적으로 등록하고 새 버전에 다시 추론한다. 실물 완료 권한을 만들지 않는다. |

**신규 개발 / 재사용.** 9/26 시작한 기존 관찰·상태 엔진을 재사용했다. 10/2 신규분은 공개 사진 검토·재사용·버전별 증거 UI/API와 독립 비교 도구이며 후보는 실험 전용이다. Qwen3.6-27B/MLX 4-bit·FastAPI·SQLite와 AI 코딩 도움은 별지2 신고 항목이다. 기반 모델을 자체 학습하지 않았다. 기본 `spatial_guarded`·1536px이며 사전 원형 사용의 주최 측 허용 여부는 미확인이다. [기여 구분](CONTEST_PERIOD_CONTRIBUTIONS.md).
