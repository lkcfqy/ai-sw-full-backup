# 공개 사진 자료 검토 Agent — 3분 시연 초안

2026-10-02 작성. **韩文为口播，中文为操作者注释。当前是脚本草案，不是已完成的演示或实验。** 尚未取得的结果全部用 `【待填…】` 标记；不得直接带占位符录制最终视频，也不得自行补入预计值。

## 演示配置与真实性

- 使用正式验收的应用、韩文界面和真实 MLX。最终版本/模型/模式/协议：`【待填：本次实际运行身份】`。候选未晋升就继续使用当前生产模式，不能用实验结果替换应用结果。
- 主样例固定为目录中的 `bag-revision`：MVTec LOCO screw_bag `train/good/016.png`，CC BY-NC-SA 4.0。它是已公开、已用于开发的演示样例，不属于本轮新51图。
- 演示 R1 预设 BOM：bolt3 / nut2 / washer2 / bracket0。R2 预先写好的**演示订单变更**：bolt2 / nut2 / washer2 / bracket0。这是虚构的订单需求情境，用真实公开照片核验；不是收到真实客户订单，也不是根据模型答案临时改成通过。
- 选择“沿用公开照片”表示同一视觉证据与新订单重新比较，不表示实物补件或新拍摄。第二次仍须真实调用模型，旧结果不可复用成新结果。
- 人的审核由实际演示操作者在查看之后填写。代号自报，仅标识本次演示，结论可同意、需资料、不同意或无法判断；不计真实用户研究或反馈加分。自动代理不能冒写人类判断。
- 原始连续录屏与逐次运行文件保留。最终视频≤180秒；可缩短真实等待段，但屏幕标 `추론 대기 일부 생략 · 실제 소요 【待填】초`（省略部分推理等待，实际耗时待填），并保持前后同一检查ID/顺序。不得把预录或剪辑说成现场实时无等待。

## 0:00–0:20｜问题和资料范围

**画面：** 标题、真实应用订单区；不要用装饰动画挤占时间。

**韩文口播：**

> KitGuard는 사진 속 부품 수량을 현재 주문과 대조하는 자료 검토 Agent입니다. 주문이 바뀌면 예전 검사 결과를 그대로 쓸 수 없고, 사진이 불명확하면 사람이 다시 확인해야 합니다. 오늘은 공개 실사 사진으로 이 흐름을 보여 드리겠습니다.

**中文注释：** 重点是订单版本与可复核审核，不说通用工业质检。常驻小字幕：`공개 개발 예시 · 실제 모델 실행 · 실물 출고 아님`。

## 0:20–0:35｜来源、R1与首次调用

**操作：** 点 `공개 사진으로 시작`，选 `봉투 키트 · 주문 변경`，展示来源与 R1 数量；点 `사진 검사 실행`。

**韩文口播：**

> 이 사진은 MVTec 공개 데이터입니다. 원본 출처와 이용 조건을 함께 기록합니다. 첫 주문은 볼트 세 개, 너트 두 개, 와셔 두 개입니다. 로컬 모델이 사진을 관찰하고, 프로그램이 현재 주문과 차이를 계산합니다.

**中文注释：** 数据来源可显示 `MVTec LOCO · CC BY-NC-SA 4.0`。模型观察不接收预期数量；可在技术说明/工具轨迹解释，避免逐段念代码。

## 0:35–1:05｜实际观察、工具和下一步

**画面：** 推理时显示实际已执行工具阶段；结束后显示实际数量与决定。

**韩文口播（先读实际结果，再选一条分支）：**

> 실제 관찰 결과는 【待填：本次实际观察】입니다. 실행한 도구와 근거를 확인할 수 있습니다.

如实际给出明确差异：

> 현재 주문과의 차이는 【待填：实际差额】입니다. 이 결과는 지금 사진과 주문 버전에만 해당합니다.

如实际弃权/需资料：

> 현재 사진만으로는 확정할 수 없어 추가 자료가 필요하다고 표시합니다. 모르는 수량을 임의로 채우지 않습니다.

**中文注释：** 只念符合实际输出的分支。模型若明确计数错误，保留输出并说 `관찰 결과에는 오류가 있어 사람의 확인이 필요합니다.`（观察存在错误，需要人核查），不要重试到满意或用作者真值替换画面。

## 1:05–1:30｜演示订单变更和旧证据失效

**操作：** 按预先设定情境将 R2 改为2/2/2/0；显示旧检查失效。点 `같은 공개 사진으로 새 버전 검사`，读清同图回放确认后登记，再点 `사진 검사 실행`。

**韩文口播：**

> 미리 정한 시연 지시로 볼트를 두 개로 바꾸는 제안을 받고, 제가 확인한 뒤 승인합니다. 주문은 사용자 지시와 명시적 승인으로만 바뀝니다. R1의 차이는 그 버전 이력에 남습니다. 같은 공개 사진을 재사용해 R2를 새로 검사하며, 새 촬영이나 실물 보충은 아닙니다.

**中文注释：** “订单情境”在录像中可见；3→2来自预设操作者指令和显式批准，不是AI为变绿擅改目标。固定R1下的差异仍在R1记录中，R2相符也不证明补件成功。可常驻一句 `사용자 지시·승인으로만 주문 변경`。若 UI 状态未按上述发生，先修复/核实，不能用口播掩盖。

## 1:30–2:00｜新的检查与 Agent 状态

**画面：** 展示新检查ID、R2与实际结果；将旧检查与新检查的版本区分清楚。

**韩文口播：**

> 새 검사 결과는 【待填：第二次实际决定与计数】입니다. 이 Agent는 수량만 답하는 것이 아니라 주문 버전, 사진, 검사 결과를 연결합니다. 주문이나 근거가 달라지면 이전 판단을 현재 결과로 사용하지 않으며, 근거가 부족하면 추가 검토로 넘깁니다.

**中文注释：** 演示的是软件实际状态与工具调用，不宣称模型自主自由规划。如果两次调用超过时间安排，按上方规范剪等待并保留原始完整录屏；没有实际测量时不要给“通常几秒”承诺。

## 2:00–2:30｜真实人的数字判断和证据包

**操作：** 实际操作者查看结果，点 `디지털 검토 기록`，填自己的演示代号、实际选择、具体依据，确认仅数字资料；导出证据包，打开离线记录。

**韩文口播：**

> 검토자는 결과를 읽고 동의하거나, 추가 자료 요청 또는 다른 판단을 기록할 수 있습니다. 제 검토 결론은 【待填：操作者实际结论】입니다. 기록에는 AI의 원래 판단, 사진 출처, 주문 버전과 검토 의견이 함께 남습니다. 이 기록은 디지털 자료 검토이며 실물 완료나 출고 승인은 아닙니다.

**中文注释：** 备注写实际查看的依据，不预填“完全正确”。如需展示“旧审核历史失效”，应真实在 R1 时也完成一次人的审核并保留录像；不必为了这一额外画面挤占3分钟，旧检查失效已是主流程要求。不要把审核同意当作作者真值或模型准确率。
