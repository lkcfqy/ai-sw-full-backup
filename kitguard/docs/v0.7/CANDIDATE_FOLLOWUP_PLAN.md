# 候选方法的后续决策计划

记录日期：2026-10-02。新51三方法试验运行期间记录，尚未使用其部分成绩挑选下一步。

`selective_identity_experimental_v1` 是研究候选，没有注册为生产 `LocalVision` 模式。它明确拒绝参考图片和前序上下文，且实验身份结果单独保存，不伪造“两方向均已执行”的生产身份协议。因此即使新51的门槛全部通过，也不能只改启动环境变量便发布成默认模式。

## 顺序

1. 完整结束冻结的153次观察，并完成独立原始记录审计。任何失败、弃权、错误都留在原分母。
2. 按冻结门槛作决定。候选必须同时满足零明确错误/执行失败/规则错误就绪、C至少46且不少于guarded、相对单次C损失不超过3、中位不超过60秒且不超过guarded的80%。未通过时保留默认，不根据新51中的错例修改候选后重称留出结果。
3. 通过仅表示值得进一步验证。另行预先冻结全部历史64作为**已曝光回归集**，覆盖其中原来的正常16、数量异常16和散装32，不按候选表现删图。可以核对是否保持历史guarded的C至少59、W/E及规则错误就绪均0、原来两个错误病例是否仍被阻断；这不是新的独立准确率。
4. 如要产品集成，需另行决定参考图和前序上下文行为，生成正确的新方法身份，并以固定原始输出重放证明普通无参考分支与实验候选一致。执行真实应用的数量差异、订单改版和资料不足分支；所有记录显示实际方法，旧记录不能因新模式切换而自动成为当前可审查依据。
5. 仅在完整证据支持后作明确的版本选择，并更新报告、技术页、PPT、视频、源码和操作说明。同一份材料中的生产模式必须一致。产品准备与补充研究可分别交付，禁止把尚未集成的候选说成已上线功能。

## 即使实验改善，也保持的边界

- 三方法使用同一基础模型，局部精查目标仍由该模型选择；未识别出的物体可能不会进入精查。
- 省去旋转调用可能减少等待，也可能失去针对某些错误的拦截。只按完整、对应范围的实际结果描述。
- 本轮无角码阳性、无新拍摄现场任务、无真人效率数据。不能以机器端调用减少推算节省工时或比赛名次。
- 若不具备足够集成验证，本轮交付保持 `spatial_guarded`，将候选的完整结果作为可复查研究成果附上。


## 实际决定（2026-10-02）

新51完整结果已出：selective C46/W4/U1，guarded C41/W3/U7。候选虽较快却新增1个明确错误，不通过预设进一步验证门槛。因此本计划的条件性旧64候选回归未启动，候选不晋升。新51从本次分析起已曝光，后续修复必须明确当作开发/历史回归，不能重称新留出。正式原记录与失败保持不变。
