## 本机运行

在项目目录执行：

```bash
bash scripts/run_detector_lab.sh
```

打开 <http://127.0.0.1:8767/static/detector.html>。也可双击项目根目录的 `启动检测验证台.command`。当前本机已有依赖及首轮权重；学校GPU型号、权限和可用时间仍未确认，不是本次运行前提。

| 配置 | 默认值 |
|---|---|
| `KITGUARD_DETECTOR_CHECKPOINT` | `training-runs/public_detector_v1_mps_20260930/best.pt` |
| `KITGUARD_DATA_DIR` | 项目内 `data-detector-lab/` |
| `KITGUARD_PORT` | `8767`，仅监听本机 |
| 检测设备 | CPU子进程；页面不提供设备或阈值修改 |
| 首轮冻结模型 | 第10轮，阈值0.5 |

独立启动脚本使用独立工单库；页面上的“返回工单工作台”返回同一服务。普通 `run.sh` 仍使用原默认端口/数据目录及Qwen工单流程。检测页面只是实验观察入口，尚未替换工单观察器。

新环境可安装包的 `detector` 可选依赖组（torch/torchvision），并另行提供本地checkpoint。轮子不附带数据、权重或训练脚本；训练与新照片批处理使用源码目录。数据来源及许可证见[首轮训练记录](../training/PUBLIC_DETECTOR_V1.md)。

上传图会去除元数据、按EXIF转正为RGB PNG，最长边缩至2048px。服务保存归一化图片、原上传SHA-256及检测记录，不保留原上传文件字节。图框坐标对应保存图片。界面下载的任务JSON用于观察追溯；新照片批量评测请按指南用单图CLI生成预测文件，不将界面任务JSON直接充当评测输入。
