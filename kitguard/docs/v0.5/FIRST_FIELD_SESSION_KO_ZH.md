# 첫 현장 수집 세션 / 第一轮实物照片验证

这是一份尚未执行的采集计划。当前真人现场样本仍为0。目标是用新拍的真实物料照片检查产品可用性与计数表现，不预设准确率或节省时间，不把12例试点当作工业可靠性证明。

## 준비 / 准备

两名队员分工：一人负责场景与真值，另一人负责照片核验。真值负责人逐类实际清点，重新清点后双次录入；操作者在人工核验结束前不查看真值。双次输入一致仅是防输错机制，独立清点真实性仍取决于操作者。同一浏览器没有账号或权限隔离，真值隔离依靠人员安排，不能称为系统盲测。

使用真实螺栓、螺母、垫圈与L形角码。没有某类实物，就如实记录未覆盖，不能用图纸、生成图或网络图冒充。每个订单每类0至3件，总需求1至12件。小部件放在稳定台面，避免人脸、证件或私人桌面信息入镜。

打开 http://127.0.0.1:8765/static/study.html 。创建批次前确定计划N（建议12例，物料不足时事先减少并说明），来源选择 self_reported_physical。创建后不能修改计划数量；已有批次必须关闭并保留原分母，必要时另建批次。不能因为失败删减分母。

## 预定12例的覆盖目标

| 编号 | 场景目标 | 要观察的行为 |
| --- | --- | --- |
| 01–03 | 简单背景，单一类别，由清点者安排数量 | 明确输入的基本计数与人工判断 |
| 04–06 | 多类别，数量符合或不符合订单，由清点者事先安排 | 缺少与多出是否都能被发现 |
| 07–09 | 背景有不属于本订单的固定物件，操作者自己选择范围 | 是否容易正确选择范围、是否漏框或切断物件 |
| 10–12 | 合理的轻度遮挡、反光或邻近摆放 | 能否保留不确定性、要求补证而不硬给就绪 |

这些是安排目标，不是已取得的结果。具体真值由实物决定，不为让模型答对而选图或改数。不得为了达到12例而把同一照片裁剪12次；每例使用新的物料布局和新照片，保留全部尝试。软件识别已知字节与来源关系，不认证物理独立性。

## 순서 / 整批准备与逐例执行

先为全部计划案例完成以下第1至3步，再统一冻结批次一次。冻结后不再新增案例；随后对每例执行第4至5步，最后整批执行第6步。

1. 清点者布置真实物料、记录真值和目标订单，拍摄完整场景，记录光照/背景和类别覆盖。
2. 建立工单并上传。若需要选区，由操作者确认全部本次待核物件在范围内；保存整图和裁图。范围声明不能代替事后复核。
3. 将该版本、照片与范围登记到验证记录台，清点者输入真值与来源说明。登记后该工单范围锁定。
4. 全部案例登记后冻结批次。每例在验证记录台点击“开始人工计数”，完成计数并记录人工数量，再点击“开始KitGuard”执行一次核验。不要提前在工作台核验已登记照片，否则会造成事先观察并阻断该案例。人工计数和模型面对同一冻结输入范围。不要在两阶段之间移动物料、改照片或改订单。
5. 保存实际核验，包括超时、失败和未完成。AI返回补拍或人工复核时仍绑定实际check并完成该次记录，结果统计为不确定U，不能改记为操作者放弃。真正失败或放弃须写原因；AI请求尚在运行时暂不能关闭批次。不要重试直到成功后只保留最后一次。
6. 全部计划案例处置后关闭批次，导出JSON和照片ZIP。复核范围完整性及真值，报告全部偏离计划事项。

## 报告边界

记录台固定人工先于AI。操作者选区时可能已经看过照片，计时不含布置、拍摄与选区，不能当作首次观察耗时。学习、记忆与固定顺序可能影响时间，脚本或操作者的界面时间不能直接解释为“节省X%人工”。它衡量固定照片任务，不衡量整条真实出库流程。真实物料调整、重新拍照、搬运、复核和出库时间如需研究，应另立协议，不和本轮混算。

最少报告：计划N、已开始N、完成N、失败/未开始N、人工完整计数正确数、AI完整计数正确数、AI明确错误数、不确定数、执行失败数；按类别和场景列出逐例。保留错误案例截图和来源SHA，注明哪些类别根本没有实物覆盖。计时报告每项分母和过程，不只给成功者平均值。

若发现真值录入错、选区漏物件或照片变动，不静默覆盖旧记录。保留原记录与带日期偏差说明。若另立批次，使用新工单与新照片，分别报告；已经登记的同源照片不能再次登记为现场案例，不能靠纠错伪增N。若系统缺少记录该偏差的字段，在导出旁保存有日期的说明。

이 세션은 새 실물 사진의 작은 사용성 시험입니다. 현장 전체 업무의 생산성이나 산업 신뢰성을 입증하지 않습니다. 사람 먼저, AI 나중의 고정 순서 때문에 시간 차이를 인과적 절감 효과로 설명하지 않습니다.
