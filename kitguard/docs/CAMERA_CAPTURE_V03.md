# v0.3 拍摄与新证据采集

此改进面向真实零件的后续采集。它没有运行模型评测，不改变或重算 v0.2 成果，也没有产生真人效率或识别提升成绩。

## 解决的实际问题

原界面已有网页相机，但点击拍摄会立即上传，缺少照片复核、重拍、明确故障恢复与待权限请求取消保护。新流程是 **拍摄 → 在设备上复核 → 明确保存**。没有照片库存时，可使用电脑内置/外接相机拍摄；参考零件管理中每类也有相机入口，可直接拍一件已知类别的参考物。

1. 创建或选择当前工单，点击空照片区或工具栏的“相机”。后续补证按钮也直接进入拍摄。
2. 只拍零件，移开人脸、证件、屏幕和私人文件。没有打印托盘也可以把物件分开放置，完整拍到边缘。
3. 让螺栓头、孔洞、零件轮廓清楚，避免重叠、反光、抖动和裁切。界面只提供人工检查指引和实际像素尺寸，不给伪造的质量分或“清晰度合格”判断。
4. 允许浏览器访问相机。存在多个可用视频输入时可切换镜头；只请求视频，不请求音频。
5. 拍摄后相机立即停止。检查照片；不满意可重拍，取消则丢弃未提交的临时照片。只有按“将此照片保存到 Rn”才上传。
6. 照片保存后另行运行核验。保存或拍摄不触发模型核验，更不自动人工确认完成。

只支持四类粗分类：螺栓、螺母、垫圈、L 形角码。工单每类 0–3 件，总计 1–12 件；不识别精确 SKU、规格或材质。参考照片须仅拍所选类别的一件物体，更新参考图仍会使旧核验失效。

## 手机与故障恢复

当前服务仍只监听电脑的 `127.0.0.1`。另一部手机不能把自己的 localhost 当作这台电脑访问，改进没有开放局域网或公网端口。可先用手机相机拍新照片，通过 AirDrop、数据线等传到运行工作台的电脑，再选入复核。

“设备拍摄 / 选择照片”使用浏览器原生文件输入及 `capture="environment"` 提示。支持该提示的移动浏览器可能调用后置相机，但浏览器行为与安全连接要求不保证相同；桌面通常打开文件选择器。HEIC 请先导出 JPG。没有相机、权限被拒绝、设备被占用或缺少安全上下文时，分别显示恢复说明，并保留文件入口。

界面有韩语和中文，手机宽度下按钮换行、预览保持完整比例，内容可滚动。真实手机摄像头、iOS Safari 与多镜头物理设备仍需现场验证；当前浏览器测试不能代替这些验证。

## 上传、隐私与版本约束

- 预览视频不发到服务器、不记录音频；拍下的一帧仅在内存中形成待确认 JPEG。网页相机帧保留全幅比例，最长边最多 2048px，JPEG 质量 0.95。该 JPEG 才是浏览器提供的上传文件，不声称保留原始视频帧字节。
- 原生选择的文件不在前端重编码。两种入口均先本机解码复核，再沿用现有照片/参考上传路由和服务器校验，存储及推理处理不变。
- 拍摄会话固定 `order_id`、开始时 `revision` 及可选参考 `part`。提交时发送该 `expected_revision`；工单照片和参考照片均依赖服务端事务检查。版本变化时拒绝上传，不自动改挂新版本。
- 关闭、Escape、页面离开或后台挂起会释放摄像轨道；旧权限请求后来成功返回也会停止其轨道，不能接管新会话。切换相机、重拍或关闭时清理旧临时 URL。后台暂停后需主动重新打开相机。
- 上传已明确发出时禁止 Escape/背景点击关窗，避免把正在发生的写入误解为“已取消”。导航中断不等于撤销已被服务器接受的上传。
- 复核清单只是拍摄建议，不证明现场身份、真实拍摄时间、物料操作或照片质量。已保存的照片仍按既有版本和证据失效规则处理。

## 可选双方向清单的历史文字

若后端返回 `observation_verification.mode=spatial_consensus`，历史详情显示“同一模型的双方向物体清单核对”。说明数量冲突或不确定时补拍、两次调用相关且可能一起出错，不称独立专家或概率。各 pass 坐标属于各自方向；第二轮旋转点不直接叠在原图。顶部仅使用后端 `object_evidence` 的首轮原图点，补拍矩形标作“估计补拍区域”，不称真值检测框。旧双方向观察记录保持兼容；本界面适配不代表已选定该策略。

## 工程验证证据

`test-results/browser/camera-v03/` 保存独立实际 API 服务、浏览器脚本、数据、截图和 `result.json`。服务使用 `NoInference` 观察器，任何推理调用都报错，不伪造成功观察；未加载 GPU。Chrome 使用明确的 fake video source，订单名含 SYNTHETIC CAMERA ENGINEERING，图片不是现场照片。

37 项浏览器断言验证：拍摄零 POST、复核后单次上传、停止视频轨道、重拍、过期版本 409、参考类别与版本、取消后晚到权限、后台暂停、旧原生文件选择不能进入新会话、上传中 Escape、防止自动 inspect/complete、中韩界面、390px 手机无溢出和可选一致性说明。没有 JavaScript 页面错误。重复修复检查属于同组工程回归，不是新增独立模型样本或用户研究。最终成功订单 ID 保存在结果文件；所有尝试仅写本测试目录的 `data/`，未修改生产 `data/` 或 v0.2 交付包。
