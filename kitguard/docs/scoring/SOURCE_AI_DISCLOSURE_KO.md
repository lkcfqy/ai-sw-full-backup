## 2. AI 개발 보조와 현재 제품 추론

**OpenAI Codex를 광범위하게 사용했습니다.** 팀의 요구에 따라 코드 생성·수정, 테스트 작성·실행, 실험 구현과 분석, 저장 결과의 재계산, 브라우저 조작, 한국어 보고서·발표자료·영상 원고 제작과 검수에 사용했습니다. 이번 제출 준비에서는 **Codex 하위 에이전트 3개를 자료 정리·제작·검수에 사용했습니다.** 이전의 AI 독립 재계산과 이번 하위 에이전트 검토 모두 AI 보조이며 사람 검토자나 사용자 참여로 집계하지 않습니다. 모든 코드를 팀원이 직접 작성했다거나 AI를 일부 문장 교정에만 썼다고 표시하지 않습니다.

자동화 조작자는 `ENGINEERING-AGENT` 등으로 기록하고 공학 리허설로 구분했습니다. 사용자 요구·개발 범위는 팀이 정했으며 최종 신고와 제출 정보는 팀원이 확인합니다.

현재 제품의 사진 관찰은 기존 **Apple M5 Pro / 64GB**에서 **Qwen3.6-27B의 MLX community 4-bit 변환**으로 실행합니다. 고정 revision은 `c000ac2c2057d94be3fa931000c31723aac53282`이며 기본 방식은 `spatial_guarded`, 최대 변 1536px입니다. 기반 Qwen VLM을 새로 학습하거나 미세조정하지 않았습니다. 별도 검출기·분류기 연구 학습은 아래와 같이 구분합니다.

사용자가 현재 사진·BOM 검토 목표를 맡기면 주문 ID·revision·evidence epoch·photo ID를 확인하고 수락 시 해당 입력을 고정합니다. 실제 사진은 VLM이 관찰하고 명시적인 규칙 상태 기계가 수량 차이·추가 자료 요청·일치 기록으로 분기하여 도구 실행과 증거 저장을 수행합니다. 입력이 바뀌면 오래된 목표는 거절하며 실패한 경우에도 준비한 입력과 오류를 보존합니다. 공개 시연의 R1→R2 변경은 실행 전에 정한 모의 주문 변경입니다. AI가 관찰 수량에 맞춰 BOM을 자동 수정한 것이 아닙니다.

현재 제품은 사용자 사진을 외부 클라우드 LLM API로 보내는 추론 경로를 사용하지 않습니다. 개발 중 Codex 서비스 이용과 공개 자료 조회는 제품의 로컬 추론과 구분합니다. 준비된 환경에서 로컬 실행이 가능하며 새 환경의 의존성·모델 준비는 별도 설치 단계입니다.
