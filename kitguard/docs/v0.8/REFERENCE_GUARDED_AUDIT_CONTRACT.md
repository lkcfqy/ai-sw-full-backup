## 原始证据重放

用 CPU 重做冻结的实际上传/JPEG 归一化、目标长边 1536 预处理、90° 旋转、两张参考长边 512 预处理及身份目标选择/裁剪。冻结 `LocalVision._observe` 的 `_load` 被设为硬错误；`_generate` 只消费本次已保存原始返回字符串，不允许模型加载或推理。

逐调用核对准确的 system/prompt/schema/token budget、实际输入图的顺序和字节 SHA，严格验证：

1. 首轮图一等于旧 G 实际目标输入，后两图依次为固定 nut/washer 参考。
2. 第二轮图一为首轮实际输入的精确 90° 变换，后两参考完全相同。
3. 若原规则触发身份检查，其输入只有目标全图和原规则生成的目标裁剪，不带类别参考。
4. 原始文本重新严格解析，解析后对象等于保存对象；调用无重试、总数最多三次。精确比较最终观察与全部诊断，包括目标、坐标、裁剪、身份响应和失败诊断。只排除不可用 CPU 重现的观察顶层墙钟 `latency_ms`；原始记录时间保留并核对包含关系。

解析错误和身份 ID 契约错误需能从保存原文重现。无原文返回的运行异常保留 E 和原异常记录，并明确内部失败原因不能重现。记录显示阶段契约异常但可回放为成功时，审计拒绝通过，不能将其悄悄算作成功。失败/缺失均不证明安全。
