# MANTA 数据许可原文复核

2026-10-02 KST，仅读作者网站 HTML 与作者链接的 Figshare 元数据；未下载 MANTA 数据包、未浏览数据图片、未推理。

**作者的非商业许可表述明确针对数据本身。** [作者项目页 Dataset Information](https://grainnet.github.io/MANTA) 写道：

> The MANTA dataset is licensed under the Creative Commons BY-NC-SA 4.0 license.

同一段进一步限制：

> All data must not be used for commercial purposes.

这段位于数据下载区之前，表述对象是 MANTA dataset / all data，不能混同于页面底部的网站模板许可。它为严格非商业、署名及相同方式共享的研究使用提供了明确的作者声明；不据此声称本项目任何未来商用、客户部署或比赛场景均已获得许可。

作者链接的两份 Figshare 记录 [27937518](https://figshare.com/articles/dataset/manta-mechanics-button_gear_nut_nut_cap_red_washer/27937518) 与 [27937521](https://figshare.com/articles/dataset/manta-mechanics-terminal_screw_wrie_cap_square_button_cap_yellow_green_washer/27937521) 的 API `license.name` 均为 **CC BY 4.0**，所以两个官方表述仍不一致。本项目不能用 Figshare 的更宽松元数据覆盖作者明确的非商业要求，也不能自行宣布冲突已被消除。

建议：下一轮若选择该来源，应明确以作者较严格的非商业数据条款约束研究、保留署名及许可原文、单独处理分发/派生材料问题，并在具体用途有疑义时向作者确认。当前只完成许可查证；没有将 MANTA 纳入模型开发、冻结评测或图片发布。

原网页及两份 API 响应已保存为小型来源快照，抓取时间、URL、字节数及 SHA-256 见 [source_receipt.json](../../datasets/manifests/v0.8/manta-license/source_receipt.json)。这些快照不含数据归档。
