## 视觉核查只支持布局

progress_audit 实际看完六张 sheet 的 36 条固定样本：五个面板横排、右侧实际输入对应第 0 面板并已灰度化、目标可见外轮廓完整、未见邻面板侵入。少量透明/纤维样边缘细节保留，未修图或重标。这里的 accepted 只表示抽查到的布局处理可用，不能扩大到全 1024 条语义认证。

36 条中包含 8 条事前指定的 validation 布局 QA；因此 validation 不叫图像盲测。全部角色、样本、视角、超参保持原冻结决定，不能根据 QA 换图。root 另做独立布局审核与单独训练批准；本 AI 回执和原准备收据均 `training_authorized=false`。

## 颜色以外还有裁剪和补黑捷径

以下仅用全部已保存的尺寸元数据统计，没有因此打开非 QA 新图、拟合阈值或修改变换。分位数为排序后线性插值。

| 项目（每类 n=512） | nut：min / P25 / median / P75 / max | washer：min / P25 / median / P75 / max |
|---|---|---|
| 原单面板宽，px | 266 / 347 / 349.5 / 351 / 387 | 342 / 346 / 348 / 349 / 361 |
| 原单面板高，px | 360 / 374 / 377 / 379 / 388 | 346 / 350 / 351 / 353 / 361 |
| 宽高比 | .729 / .921 / .926 / .933 / 1.029 | .955 / .983 / .991 / .994 / 1.026 |
| 224 适配后左右补黑总宽，px | 0 / 15 / 17 / 18 / 61 | 0 / 1 / 2 / 4 / 10 |

补黑数由冻结的等比例缩放几何计算，是两边合计，不是逐像素判断天然黑背景的面积。两类上下补黑的中位数均为 0、最大 6 px。

抽样中 nut 为浅色六角轮廓，washer 为黄绿圆环；转灰度后，轮廓、亮度、背景处理以及原裁剪宽高比仍可能提供类别线索。尤其补黑总宽中位数 17 vs 2 px，提示存在预处理相关捷径的风险。**这不是训练结果，也没有证明模型必然使用这些线索。** 固定预处理照原协议保留；未来即使内部高分，也不能据此宣称修复 Screws/LOCO 银色混放、开放类别拒答或数量识别。
