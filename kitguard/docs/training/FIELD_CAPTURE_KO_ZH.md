# 새 사진 수량 검증 / 新照片数量验证

이 절차는 휴대폰으로 새로 촬영했다고 사용자가 선언한 사진을, 두 번의 수동 계수와 잠금 후 예측으로 비교합니다. 실제 촬영 여부나 독립적인 블라인드 평가를 인증하지 않습니다.

这个流程把用户声明为新拍摄的照片，经过两次人工计数、锁定，再与固定模型输出比较。文件哈希用于追溯和发现改动，不能证明真实拍摄、人工独立性或没有提前看过模型结果。

## 1. 촬영과 보관 / 拍摄与保存

- 볼트/나사와 너트를 우선 준비합니다. 현재 실험 모델은 이 두 넓은 범주만 지원하며 규격·SKU를 구분하지 않습니다. 와셔와 브래킷은 미지원입니다.
- 先准备螺栓/螺钉和螺母。当前实验只支持这两类粗分类，不区分规格或SKU；垫圈、角码尚不支持。
- 서로 다른 배치, 조명, 배경, 촬영 거리에서 촬영하고 쉬운 사진과 겹침·반사·작은 물체가 있는 사진을 함께 보관합니다. 같은 배치의 연속 사진은 같은 촬영 세션으로 선언합니다.
- 记录不同摆放、光线、背景、距离，保留清晰照片和重叠、反光、小目标等难例。同一摆放连拍属于同一拍摄session，不应称为独立场景。
- 촬영 당시 실물 수량을 사람이 확인합니다. 사진과 실제 배치가 바뀌지 않았는지 확인하고, 확정할 수 없는 값은 `null`/`pending`으로 남깁니다. 모델 출력을 정답으로 옮기지 않습니다.
- 人工核对拍摄当时的实物数量，确保对应的摆放没有变化。不能确认时保持 `null`/`pending`，不得复制模型输出充当真值。
- JPG/JPEG/PNG 원본을 별도 폴더에 넣습니다. 편집·합성·스크린샷이나 공개 데모 사진을 새 현장 사진으로 신고하지 않습니다. 이 도구는 HEIC를 받지 않으므로 휴대폰에서 JPEG 원본으로 내보내고 변환 사실을 출처 선언에 적습니다.
- 将JPG/JPEG/PNG原文件放在独立文件夹。编辑图、合成图、截图或公开演示图不能申报为新实物照片。工具不接收HEIC，可从手机导出JPEG，并在来源声明记录转换情况。

建议先采集一个能全部认真核对的小批次，例如12–20张，保留所有计划场景。不要依据模型是否答对选择入组或删除难例。这个数量只是启动建议，不代表统计充分或比赛成绩保证。

처음에는 계획한 장면을 모두 수동 검토할 수 있는 12–20장 정도의 작은 배치를 권합니다. 모델 정답 여부로 사진을 고르거나 어려운 사례를 삭제하지 않습니다. 이 수량은 시작 제안이며 통계적 충분성이나 수상을 보장하지 않습니다.

## 2. 배치 가져오기 / 导入批次

以下命令从KitGuard项目根目录执行。路径仅为示例，替换为自己的照片文件夹和**尚不存在**的输出目录。

아래 명령은 KitGuard 프로젝트 루트에서 실행합니다. 예시 경로를 실제 사진 폴더와 **아직 없는** 출력 경로로 바꿉니다.

```bash
.venv/bin/python scripts/prepare_detector_field_batch.py prepare \
  --images-dir /absolute/path/to/new-photos \
  --output-dir field-batches/session-01
```

生成文件 / 생성 파일：

- `images/`：逐字节复制的原文件，不改像素；원본 파일을 바이트 단위로 복사합니다.
- `batch_manifest.json`：case ID、原图SHA256、EXIF转正后的RGB像素SHA256、尺寸和来源排除覆盖报告。
- `annotation_a.json`、`annotation_b.json`：两份独立填写模板，四类数值全部初始化为 `null`，状态为 `pending`。

原始文件hash与EXIF转正像素hash任一重复，批次拒绝导入。公开来源筛查包括：

| 来源 / 출처 | 预期登记记录 / 예상 등록 수 |
|---|---:|
| MVTec Screws，全部官方分割 | 384 |
| MVTec LOCO screw_bag，全部已登记分割 | 761 |
| InO-10-190，origin/cropped的color/depth PNG | 760 |
| v0.3正式评测视图，含裁剪 | 76 |
| 三份InO派生视图清单 | 20 + 1 + 3 |
| 产品公开演示目录，含small-part/mixed-screws裁剪 | 3 |

共2008条登记记录，来源间存在重复，不等于2008个独立场景。manifest另列去重后的hash数量。已知文件丢失时仍检查登记的原文件hash，但缺少该文件的像素覆盖；缺少清单时相应来源不能覆盖，`all_expected_sources_covered`为`false`并逐项记录缺口。已登记清单或原文件hash不符时拒绝继续。

등록 기록은 총 2008개이며 출처 간 중복이 있어 독립 장면 수가 아닙니다. 중복 제거한 해시 수는 manifest에 따로 기록합니다. 파일이나 목록이 없으면 확인하지 못한 범위를 명시합니다. 등록된 해시가 달라지면 작업을 중단합니다.

**完全覆盖只指这些已登记文件的精确重叠筛查。** 未登记裁剪、缩放、重新压缩、近似图和真实拍摄来源都无法全面认证。公开演示图也不能作为新现场样本。

**전체 커버리지는 등록된 파일의 정확한 중복 확인 범위입니다.** 등록하지 않은 크롭·리사이즈·재압축·유사 이미지나 실제 촬영 출처를 모두 인증하지 못합니다.

## 3. 두 번 수동 계수 / 两次人工计数

在运行预测前，分别填写 `annotation_a.json` 与 `annotation_b.json`。建议两人分别计数；同一个人两次核对也可以，但只记录本人声明，不能宣传为独立双人审核。

예측 실행 전에 두 파일을 각각 채웁니다. 두 사람이 따로 계수하는 방식을 권합니다. 한 사람이 두 번 확인할 수도 있지만 독립적인 두 사람의 검증으로 표현하지 않습니다.

每份文件都要填写 / 각 파일에서 입력할 항목：

1. `annotator`：实际填写者的姓名或稳定代号；실제 작성자의 이름 또는 고정 식별자.
2. `counted_without_model_predictions`：确实未参考模型结果才填 `true`；모델 결과를 보지 않았을 때만 `true`.
3. 每个case的 `counts`：人工确认的非负整数。**0只表示人工确认不存在**，未知不能填0。
4. 已完成核对的每个case将 `status` 改为 `complete`。不要改case ID或source hash。

选择 `bolt_nut` 范围时，填写 `bolt`、`nut`；`washer`、`bracket`必须保持 `null`。选择 `four_classes` 时，四类都需要人工数值。当前两类模型无法完成四类比较，届时全部案例会保留为“未完成”，不会把未知当作0。

`bolt_nut`에서는 bolt/nut만 입력하고 washer/bracket은 `null`로 둡니다. `four_classes`에서는 네 범주 모두 수동 수량이 필요합니다. 현재 두 범주 모델은 네 범주 검증을 완료할 수 없으므로 미완료로 집계됩니다.

工具要求全部case人工完成、两份数值完全一致才允许锁定。意见不一致时回看实物和原照片，不看模型预测来裁定。无法确定时保留pending并继续核对，不要删掉难例来让锁定通过。

모든 case가 완료되고 두 수동 기록이 같아야 잠글 수 있습니다. 불일치는 실물과 원본 사진으로 확인하고 모델 예측으로 정답을 정하지 않습니다. 불확실하면 pending을 유지하며 어려운 사례를 삭제해 통과시키지 않습니다.

## 4. 정답 잠금 / 锁定真值

```bash
.venv/bin/python scripts/prepare_detector_field_batch.py lock \
  --batch-dir field-batches/session-01 \
  --scope bolt_nut \
  --source-declaration '填写真实来源、拍摄者、是否JPEG导出；공개 자료가 아닌 직접 촬영 여부를 사실대로 기재' \
  --capture-session '填写日期、地点或台面代号、session代号；예: session-01'
```

这会生成 `locked_ground_truth.json` 和 `locked_ground_truth.sha256`，记录照片清单、两份人工文件的hash、范围、锁定时间、来源/session声明。已有锁定文件不可覆盖。声明保留为用户陈述，不作为真实拍摄或盲法的独立认证。

잠금 파일은 사진 목록·수동 파일 해시·범위·시간·출처/session 선언을 기록하며 덮어쓰지 않습니다. 선언은 사용자 진술로 보관하고 실제 촬영이나 블라인드 절차의 독립 인증으로 취급하지 않습니다.

## 5. 잠금 후 예측 / 锁定后预测

用同一个已选定checkpoint，为每个case运行现有单图CLI。输入使用该批次 `images/` 中的文件，每次输出新的JSON；所有结果放在同一个独立文件夹。不要混用多个checkpoint或阈值。

동일한 선택 완료 checkpoint로 각 case의 단일 이미지 CLI를 실행합니다. 배치 images 폴더를 입력으로 사용하고 결과 JSON을 전용 폴더에 저장합니다. checkpoint와 임계값을 섞지 않습니다.

```bash
.venv/bin/python scripts/predict_public_detector.py \
  --checkpoint /absolute/path/to/best.pt \
  --image field-batches/session-01/images/REPLACE_WITH_ACTUAL_CASE.png \
  --output field-predictions/session-01/REPLACE_WITH_ACTUAL_CASE.json \
  --device auto
```

阈值来自checkpoint的验证集选择，没有手动调阈值或按订单调数量的入口。预测时间须晚于锁定时间。时间戳是本地记录，不是可信时间认证。

임계값은 checkpoint의 검증 세트 선택값을 사용합니다. 주문에 맞춰 수량이나 임계값을 조정하지 않습니다. 예측 시간은 잠금보다 늦어야 하지만 로컬 시간 기록 자체가 인증된 시각은 아닙니다.

运行失败可保留缺失结果，也可写失败记录，示例结构如下；source hash必须复制自batch manifest，错误内容按实际填写：

실패한 case는 결과를 비워두거나 다음 형태의 실패 기록을 남깁니다. source hash는 batch manifest에서 가져오고 오류는 사실대로 적습니다.

```json
{
  "source_sha256": "REPLACE_WITH_BATCH_SOURCE_SHA256",
  "status": "failed",
  "error": "填写真实错误；실제 오류 내용"
}
```

## 6. 전체 사례 비교 / 全分母比较

```bash
.venv/bin/python scripts/prepare_detector_field_batch.py evaluate \
  --batch-dir field-batches/session-01 \
  --predictions-dir field-predictions/session-01 \
  --output-dir field-comparisons/session-01
```

输出 `comparison.json`：全部case数、正确数、错误数、未完成数、全体case上的准确数量比例，以及已完成case上的比例，二者分别标注。没有输出、失败、时间早于锁定、无效结果、范围不支持都留在原分母中。重复结果、批次外来源、混用checkpoint/阈值会拒绝整个比较。

출력은 전체 case 수, 수량 일치·불일치·미완료 수, 전체 분모와 완료 분모의 비율을 구분합니다. 누락·실패·잠금 이전 예측·잘못된 출력·미지원 범위는 원래 분모에 남습니다. 중복 결과·배치 외 출처·혼합 checkpoint/임계값은 비교를 거부합니다.

锁定后改动照片、人工文件、batch manifest或锁定真值都会拒绝比较。必须纠正人工错误时，保留原批次及原结果，再准备明确命名的新修订批次，披露改动原因和是否已看过预测。看过预测的修订不能声称为未见过结果的盲测。

잠금 후 사진·수동 파일·manifest·정답이 바뀌면 비교를 거부합니다. 정답 수정이 필요하면 기존 배치/결과를 보존하고 수정 이유와 예측 열람 여부를 밝힌 새 배치를 만듭니다. 이미 예측을 본 수정본을 블라인드 평가라고 표현하지 않습니다.

比赛材料应如实写“用户声明拍摄批次上的数量比较”，同时报告样本/session数、类别范围、错误、未完成与来源覆盖缺口。这个工具本身不产生真实现场有效性、完整四类能力、SKU识别或安全放行结论。

발표 자료에는 사용자 촬영 선언 배치의 수량 비교라고 적고 사례/session 수, 범주, 오류, 미완료, 출처 확인의 누락 범위를 함께 보고합니다. 이 도구만으로 실제 현장 유효성, 네 범주 전체 능력, SKU 식별 또는 안전한 출고 결론을 내리지 않습니다.
