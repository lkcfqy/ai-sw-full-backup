事实与使用边界 / 범위와 한계

  • 64 张来自公开静态数据，不是校园或工厂现场试用；28 张开发数据与历史 48 张独立标注，未合并扩大新测试分母。
  • 多轮判断使用同一个本地模型，错误相关；无法保证发现多轮共同遗漏的零件。支架等未覆盖零件和真实环境仍缺验证。
  • 本次零错误只描述这 64 张；5 张补拍含 3 张原本正确的首轮结果，不能报告为 100% 准确率。整体中位耗时 40.58 秒。
  • 录像使用 3 张既有公开开发图片；改版批准由浏览器自动化点击，未开展真人用户研究，未声称实物完成或效率收益。
  • 启动脚本的默认方法为 spatial_guarded；直接导入模型库或绕过脚本时，必须明确指定方法。
  • 比赛资格与允许的开发时间范围仍应以主办方正式说明为准；研发记录保留实际日期，未取得豁免证明。
