## 3분 시연 순서 / 三分钟演示顺序

1. **0:00–0:30 문제와 기준.** 주문 변경이나 배경 고정물을 잘못 세면 수량 비교가 틀릴 수 있다. 현재 버전, 사진, 검사 범위를 함께 고정한다. / 展示订单、当前照片及待检范围，说明背景固定件可能造成计数范围歧义。
2. **0:30–1:10 범위 확인.** 전체 사진에서 실제 검사 대상만 포함하도록 영역을 선택하고 모든 대상이 안에 있음을 확인한다. 공개 A41 예시는 이미 본 개발 이미지이며 작성자 위치를 사용한다. / 框选并确认，展示整图仍保留。A41是已知开发图，演示框基于作者标注，不能称自动定位。
3. **1:10–2:10 실제 검사.** 모델이 물체를 열거하고 코드가 주문과 비교한다. 기다리는 동안 원본·회전 확인과 불확실 시 재촬영 원칙을 설명한다. 결과가 불확실하면 그대로 보여 준다. / 实际调用本地模型；等待时解释双方向观察和弃权。结果不确定就展示不确定，不重跑挑结果。
4. **2:10–2:40 증거 추적.** 전체 사진·선택 영역·입력 사진·해시를 포함한 ZIP을 열어 과거 검사와 연결한다. 영역 변경은 새 촬영이 아니다. / 打开证据包，展示整图、区域、裁图及旧检查失效；改框不算新拍照。
5. **2:40–3:00 검증과 한계.** 64장 동결 공개 평가 C59/W0/U5/E0와 현재 기능 연결 시험을 분리한다. 현장 효과는 아직 측정하지 않았다. / 区分历史冻结64图评测与本轮功能联调，明确尚无现场效果数据。

现场模型耗时无法保证固定，演示先确认8765健康状态和模型文件。保留事先录制的真实过程与离线证据作为断网/服务故障时的可审查材料，播放时明确说“录制回放”；不可假装现场实时推理。公开图片工单不能确认实物完工。

## 핵심 답변 / 关键答辩

- **为什么需要框选？** 计数首先需要约定范围。操作者声明范围，系统把这一决定与输入证据绑定。不能保证操作者没有漏框，整图保留用于复核。
- **是否通过裁图刷分？** v0.5没有新增无偏准确率成绩。两次联调均是已曝光开发输入；A41使用作者位置，仅验证角码作者计数，不给其他类别补造零真值。
- **为何不是普通聊天机器人？** 订单版本、证据状态、程序数量比较、弃权、人工完成确认、来源族去重和离线证据形成可检查流程；模型仍可能漏检、重复或误分。
- **能不能证明节省人工时间？** 目前不能。验证记录工具已可用，脚本人工计时不是真人基线。需新实物、新操作者、预定案例数和完整失败记录。
- **本地硬件？** 已在用户Mac的共享27B四位模型上运行。3080台式机未连接或验证，不能宣称同模型在该机已通过。
- **能保证第一吗？** 不能。当前优势是可运行的完整证据流程与审查透明度；真实场景证据、效果与参赛资格仍影响评审。
