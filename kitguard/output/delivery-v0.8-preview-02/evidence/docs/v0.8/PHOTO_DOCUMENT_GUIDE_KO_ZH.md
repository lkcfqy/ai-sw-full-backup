# 내 사진으로 자료 검토 / 使用自己的照片审查资料

KitGuard의 **내 사진으로 자료 주문**에서 로컬 사진과 주문 수량을 비교할 수 있습니다. 실물을 준비하지 않아도 시작할 수 있습니다. 공개·온라인 사진도 이용 조건을 확인하고 적법하게 확보한 파일이라면 사용할 수 있습니다. 출처와 이용 조건은 사용자의 진술로 저장되며, KitGuard가 권리나 허가를 인증하지 않습니다.

从 KitGuard 的 **用自己的照片建资料工单** 入口，可以比较本地照片与订单数量，无需先准备实物。可以使用公开或网上数据，但应自行确认使用条件、合法获取文件，如实填写来源，不把公开可见误写为已获授权。来源与许可始终标为用户自报、尚未核实。

## 한국어

1. **내 사진으로 자료 주문**을 열고 JPEG·PNG·WebP 사진 한 장을 선택합니다. 제목과 필요한 부품 수량을 입력하세요. 나사류·너트·와셔·브래킷별 주문 수량은 0–3개입니다.
2. 사진을 어디서 확보했는지 필수 출처 설명에 적습니다. 출처 URL과 이용 조건은 알고 있는 범위에서 추가하세요. **URL은 출처 기록용이며 사진을 대신 다운로드하지 않습니다.** 디지털 검토만 한다는 확인 후 등록합니다.
3. 등록된 사진과 수량을 확인하고 **사진 검사 실행**을 누릅니다. 실제 로컬 모델 결과가 나올 때까지 기다린 뒤, 관찰 수량·차이·불확실한 항목을 확인합니다. 검사가 실패하면 안내에 따라 다시 시도하세요.
4. 검토가 가능한 실제 모델 결과에는 동의, 추가 자료 필요, 이견, 판단 유보 중 하나를 선택하고 의견을 기록할 수 있습니다. 이 기록은 결과에 대한 의견이며 모델 정답 인증이나 실제 사용자 평가 점수가 아닙니다.
5. 주문 수량을 바꾸면 이전 결과가 새 주문에 자동 적용되지 않습니다. 안내에 따라 **같은 자료 사진을 재사용**하고, **사진 검사 실행**을 다시 누르세요. 새 사진을 검토하려면 별도 자료 주문을 만듭니다.
6. **증거 ZIP**을 내려받아 압축을 풀면 사진·주문·검사·검토 기록과 읽기 전용 `OPEN_ME.html`을 보관할 수 있습니다. 로컬 HTML 열기가 허용된 브라우저에서 확인하세요.

이 경로는 사진 자료 검토입니다. 같은 사진 재사용은 새 촬영이나 부품 보충이 아니며, 실물 완료·출고를 기록하지 않습니다. 흐리거나 가려진 사진은 추가 자료가 필요할 수 있고, 치수·재질·세부 규격까지 확인했다는 뜻도 아닙니다.

## 中文

1. 打开 **用自己的照片建资料工单**，选择一张 JPEG、PNG 或 WebP 图片，填写标题与需求数量。螺纹件、螺母、垫圈、角码的订单数量分别为 0–3。
2. 必须说明照片从哪里取得；来源网址和使用条件可按已知信息选填。**网址只作为来源记录，不会代为下载图片。** 确认仅用于数字审查后提交。
3. 核对已登记照片和数量，点击 **运行照片核验**。等待本机真实模型返回，查看观察数量、与订单的差异及不确定项；如果失败，按页面提示重试。
4. 对可审查的真实模型结果，可记录认可、需要更多证据、异议或暂无法判断。数字意见是对结果的判断，不代表模型一定正确，也不是用户试验成绩。
5. 修改订单数量后，旧结果不会自动适用于新版本。按提示 **沿用资料照片核验新版本**，然后再次点击 **运行照片核验**。如要换一张照片，请另建资料工单。
6. 下载 **证据 ZIP** 并解压，可保存照片、订单、核验与审查记录，以及只读的 `OPEN_ME.html`。在允许打开本地 HTML 的浏览器中查看。

此入口只审查照片资料。同图回放不代表重新拍摄、补件或现场变化，也不能据此宣称实物完工或出库。模糊、遮挡的照片可能需要补证；粗分类和数量检查不等于已验证尺寸、材质或详细规格。
