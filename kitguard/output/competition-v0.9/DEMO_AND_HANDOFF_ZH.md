# 无实物演示与交接

## 启动

现有电脑双击项目内 `启动参赛演示.command`，或运行 `bash scripts/run_competition.sh`。它使用现有虚拟环境和 `~/Downloads/AI-Models/Qwen3.6-27B-4bit`，数据写入独立 `data-competition-v09/`。浏览器打开 http://127.0.0.1:8765 。已有8765服务时先确认页面版本，不要启动重复服务。首次加载模型有等待，界面显示真实进度；不需要外部GPU或新购买部件。

全新解压的源码不附环境和模型；先按根 README 的 setup 说明安装依赖并准备相应本地权重。已测试的是现有依赖下源码解压启动，不是没有依赖的新机器一键安装。

## 6分钟演示建议

1. 先说问题：照片、订单和复核结论缺少共同的版本依据。打开公开照片审查，选择袋装套件。明确这是带许可的公开开发图，不是现场拍摄。
2. R1需要3个螺纹件、2螺母、2垫圈；点击实际检查。模型运行约50秒时讲解原图与旋转观察、固定规则工具和状态保存。不要把剪辑视频当成实时速度。
3. 开图上复核。依次选类别标出6件，确认当前范围，填写自己的审查代码和判断理由。第一次练习选“功能演练”。系统从标记算出差异，不必手填“通过”。模糊时选择需要更多资料。
4. 演示预设的需求改动：把需要的螺纹件从3改为2。强调是订单变更，照片里的东西没有增加。旧结论立即失效。
5. 明确重用同图并重新检查。若时间不足，播放随包视频或打开保存的历史，不伪装成刚发生的推理。R2复核后可以得到数量相符；原AI观察和R1差异都还在。
6. 下载证据ZIP，解压看OPEN_ME.html，展示标记和原AI/复核对照。当前机器回放已验证本地静态服务器；浏览器不允许file://时可在解压目录用Python http.server，勿更改浏览器安全设置。
