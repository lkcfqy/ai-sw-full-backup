# v0.3 발표 보충 QA

최종 6장 PPT를 ArtifactTool로 다시 가져와 각각 1920×1080 PNG로 렌더하고 모든 페이지를 개별 확인했다. `visual-qa.json`에 최종 파일과 렌더 해시를 기록했다. `validation.json`은 패키지·폰트·레이아웃·재가져오기 결과, `sources.json`은 전체 완료 입력의 경로·SHA, `validated-metrics.json`은 검증된 지표이다.

PowerPoint 또는 Google Slides에서 열어 확인한 것은 아니다. LibreOffice는 사용하지 않았다. 이 폴더는 검토 기록이며 최종 발표 파일은 상위 디렉터리의 `KitGuard_검증보충_v0.3.pptx`이다.
