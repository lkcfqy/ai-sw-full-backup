기계 과제의 분기 달성과 사진 정확도는 별도입니다. 기존 51장 C41/W3/U7, 같은 공개 도메인의 제한된 LOCO24 C23/W0/U1을 분리합니다. 실제 사용자 효익·실물 완료·새 사진 정확도 개선은 이번 제출에서 증명하지 않습니다.

로컬 실행

  1. 소스 ZIP을 해제하고 KitGuard/SOURCE_PACKAGE.md를 읽습니다.
  2. 해당 폴더에서 bash scripts/setup.sh를 실행하고 고정 모델을 별도로 준비합니다. 초기 설치는 인터넷이 필요합니다.
  3. bash scripts/run_competition.sh를 실행합니다. 준비된 모델과 의존성은 로컬에서 동작합니다.
  4. 자율 검토 화면에서 전체 시나리오를 시작하거나, 홈페이지에 현재 사진과 BOM을 등록합니다.
모델·개인 주문 DB·업로드 자료는 소스 ZIP에 포함하지 않습니다. 사진의 사용권과 기존 자산을 별도 공개합니다. 이 패키지는 로컬로 검증한 제출 준비본이며 공식 접수·자격·점수·순위를 증명하지 않습니다.
