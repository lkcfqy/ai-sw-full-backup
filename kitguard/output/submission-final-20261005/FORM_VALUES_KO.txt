작품 요약
KitGuard는 사용자가 지정한 현재 사진과 주문 수량표(BOM)를 로컬 모델로 검토하는 AI Agent입니다. 주문 ID, 버전, 사진과 증거 상태를 목표에 결합한 뒤 실제 사진 관찰을 실행하고, 수량 차이·추가 자료 요청·현재 수량 일치로 분기합니다. 주문이 바뀌면 옛 결론은 만료되며 동일 사진을 디지털 재사용하더라도 새 검사를 실행합니다. 입력, 실패와 원래 모델 결과를 보존하고 오프라인 증거 ZIP으로 내보냅니다.

개발 결과 요약
현재 사진/BOM 목표, 실제 로컬 관찰, 조건 분기, 버전·독립 검토 상태, 증거 내보내기까지 연결한 MVP입니다. 사전에 정한 5개 기계 과제의 분기/거절을 확인했고, 10월5일 최종 실행은 기존 공개 개발 사진 3장·실제 MLX 검사 4회·135.542초로 완료했습니다. 소프트웨어 회귀 1,877개가 통과했습니다. 기존 51장 사진 결과는 41 정확·3 오류·7 미확정으로 남아 있으며, 새 사진 정확도 개선·실제 사용자 효율·실물 출고를 주장하지 않습니다.

주요 기술
Qwen3.6-27B MLX 4-bit, Python 3.12, FastAPI, SQLite, Pillow, HTML/CSS/JavaScript. 실제 확인 장비 Apple M5 Pro 64GB. 모델 가중치는 소스 ZIP과 별도로 준비합니다.
