# KitGuard 관련 솔루션과 구현의 위치 / 相关方案与项目定位

제품 **0.9.0.dev4** · 문서 수정 **2026-10-05 KST**

## 발표에서 전달할 가치

KitGuard의 초점은 **현재 사진과 현재 BOM을 연결한 자료 검토**입니다. 주문이 개정되면 이전 사진 검사가 현재 요구를 설명하는지 다시 확인해야 합니다. 시스템은 목표 수락 시 사진·BOM·버전·증거 상태를 고정하고, 오래된 목표를 거절하며, 실제 로컬 관찰에 따라 차이·추가 자료·일치로 분기합니다. 성공·불확실성·실패를 입력과 함께 보존하고 오프라인 증거로 내보냅니다.

이 연결은 구현된 제품의 검증 범위입니다. 사진 계수, 로컬 배포 또는 여러 도구를 연결하는 방식 자체를 세계 최초로 주장하지 않습니다. 팀이 설정한 현장 문제와 도입 수요는 아직 실제 고객 연구로 확인하지 않았습니다.

## 공식 자료에서 확인한 관련 접근

아래는 2026-10-04에 읽은 공식 자료에 근거한 위치 설명입니다. 이번 수정은 표현을 정리한 것입니다. 제품을 설치·구매·실행하거나 성능 대조를 수행하지 않았습니다. 자료에 기능이 적혀 있지 않다는 이유로 그 기능이 없다고 판단하지 않습니다.

| [MVTec HALCON Deep Counting 23.05](https://www.mvtec.com/doc/halcon/2305/en/toc_matching_deepcounting.html) | 사용자 템플릿에서 모델을 준비하고 비슷한 객체를 찾아 계수합니다. | 객체 계수는 기존 기술입니다. KitGuard의 정확도·속도가 이 제품보다 높다는 실험은 없습니다. |
| [Roboflow Workflows](https://docs.roboflow.com/workflows) | 모델·논리·통합을 다단계 시각 응용으로 연결하며 클라우드나 자체 하드웨어에서 실행할 수 있습니다. | 다단계 시각 흐름과 자체 하드웨어 실행도 기존 접근입니다. KitGuard는 현재 입력·개정 이력·판단 보존의 연결을 구현했습니다. |
| [Cognex In-Sight D900 참고 안내 1.6](https://docs.cognex.com/isvidi_160/web/en/isd900/content/topics/hardware/Intro.htm) | 독립된 네트워크 머신비전 장비로 공장 검사·측정·식별·로봇 안내를 지원합니다. | 공장용 시스템과 현재 컴퓨터의 자료 검토 MVP는 검증 환경이 다릅니다. KitGuard의 공장 신뢰성이나 대체 가능성은 입증하지 않았습니다. |

## 우리가 실제로 확인한 차이

다섯 사전 고정 기계 과제에서 수량 차이, 추가 자료, 일치, 주문 개정 뒤 오래된 목표 거절과 새 검사, 실물 주문 범위 거절이라는 예정 흐름을 확인했습니다. 세 장의 알려진 개발 사진에서 실제 MLX 검사 네 번을 수행했습니다. 같은 저장 관찰에 버전 결합을 생략한 CPU 대조에서는 이전 ready를 한 번 계속 사용하는 문제가 생겼고, 결합을 유지한 방식은 이를 거절했습니다.

이 대조는 **버전 결합이라는 구현 제약의 작동**을 설명합니다. 경쟁 서비스의 오류율, 새로운 사진에 대한 정확도 개선, 사람의 업무시간 절약 또는 시장 전체에서의 우위를 입증하지 않습니다. 기존 51장 평가의 명확한 오류 3건은 그대로 남습니다. LOCO24는 같은 기존 공개 도메인의 별도 평가 집합이며 이를 상쇄하지 않습니다.

## 발표용 문장

“사진 계수와 로컬 시각 워크플로는 기존 솔루션에도 있습니다. KitGuard는 현재 사진·BOM을 수락한 목표에 고정하고, 주문이 바뀌면 옛 결론을 무효화하며, 불확실성과 실패도 증거로 보존하는 흐름을 구현했습니다. 다섯 기계 과제와 같은 관찰의 버전 결합 제거 대조로 이 연결을 확인했습니다. 비교 제품을 실행해 정확도나 속도 우위를 측정한 것은 아닙니다.”
