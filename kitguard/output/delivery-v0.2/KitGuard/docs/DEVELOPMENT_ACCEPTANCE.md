# 当前开发阶段与验收依据

2026-09-26，用户要求自主补齐资料、持续开发并交付自检评估。名次由评审及其他参赛作品共同决定，不能作为软件自动验收的可保证结果。以以下可检查交付作为本阶段目标。

## 核心交付

1. 可在现有Mac与共享本地模型上独立运行，覆盖订单变更、真实图像观察、明确的下一步行动、复查和人工确认记录。
2. 真实公开图片有来源、许可、哈希、标签映射和固定数据划分；所有模型输出和失败保留。开发集用于改进，留出集在版本冻结后运行。
3. 无法可靠判断时不完成订单；过期版本、旧证据、重复请求、推理中状态变更和失败都经过行为测试。
4. 评委可查看一次检查的输入照片、当时需求、观察、差异、动作、时间及失效原因。改版/补证演示可以重复运行。
5. 交付自检与竞争力评估、技术说明、运行与复现说明、来源/AI使用记录，以及可演示材料。最终比赛格式在官方新模板公布后仍需对照。

## 评测预先约定

- 主单位为一张来源明确的原始实拍图；不把同图生成的多个工单算作多个独立实拍样本。
- 完整计数正确率分母包括拒绝、超时和无效输出。额外列可执行覆盖率及可执行结果中的计数错误，防止“全拒绝”伪装高可靠性。
- 在产品数量范围内，为每张图派生一个匹配订单和一个预先固定的数量不匹配订单；计数模型不接收订单目标。分别列匹配订单就绪率、错误放行和正确调整率。
- 不修改模型输出，不挑选通过案例来计算总体结果。选例、排除原因和映射须在推理前固定；真正看过结果并据之修改的样本归开发集。
- 公开图可能存在基础模型预训练污染；保留此限制，不声称独立现场泛化能力。
- 目前没有真实用户任务、现场操作前后连续照片或企业试点；不能填造相关成绩。单次VLM视觉性能与状态控制器软件优势分开报告。

## 当前验收的实际边界

技术交付完成不等于已获得参赛资格，也不等于已证明可获得第一。原始同意书存在赛前开发限制，当前工程必须如实保留时间及来源；来源披露本身不构成豁免。缺失的官方规则解释、正式评分表、自采连续操作和人类基线均在最终评估中单列。
