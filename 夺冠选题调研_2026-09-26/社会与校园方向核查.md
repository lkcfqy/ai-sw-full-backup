# 社会与校园方向核查

核查日期：2026-09-26（韩国时间）。用途：为第4届庆南 AI·SW 竞赛选题提供备选，以下竞赛表现判断属于研究建议，不是官方评审结果或夺冠概率。

## 结论

在没有企业数据和合作厂区的前提下，校园方向最值得保留的是 **「누락제로：基于证据的申请材料核验与补件 Agent」**。限定三个流程，做出公告变更/资格例外核验、实际上传材料检查、追问补正、重新验证、导出待提交包的完整闭环。胜负应建立在真实学生减少错误和减少准备时间的证据上，而不是“韩国首个留学生 AI 助手”之类无法成立的宣传。

它比制造方向更容易在八天内得到真实用户测试，但技术新颖性和产业价值叙事弱一些。若拿不到约 8–12 名自愿测试者，以及至少一名能审阅材料规则的同学/助教/行政人员，单凭漂亮界面和几个演示案例，不足以把它当作争第一的选题。

不建议选择泛留学生生活平台、签证问答、自动翻译、拍照识别隐患加生成安全报告。已有服务覆盖较多，且移民规则和真实安全任务会显著增加验证成本。

## 推荐备选的最小范围

建议韩文题名：**공고 변경과 증빙 누락을 검증하고 제출 패키지를 만드는 AI Agent — 누락제로**。

对象是昌原大研究生和外国留学生；初版语言只做韩文、中文，不扩成多语言大全。应用支持的流程不超过三个：

| 流程 | 可取得的真实来源 | 适合测试的错误 | 限制 |
|---|---|---|---|
| 本次 AI·SW 竞赛报名 | 用户已归档的学校公告、主办方公告、旧版/修订版 HWP 和报名说明 | 博士选错组、旧附件漏开发计划、截止日期/时间误读、成员证明或同意书缺失 | 仅作为一个公开案例，不能只围绕本赛写死规则后声称通用 |
| 研究生资格考试/外语免试申请 | 2026-2 学期校内公开公告及 HWP | 韩国学生与外国学生分支混淆、把免试申请误当线上考试报名、将未来生效规则提前使用 | 此批申请已经截止，只能标为历史回放测试；院系要求要单独核对 |
| 韩国语学堂课程报名/退费 | 课程公告、退费公告和表格 | 报名与退费流程错配、缺少申请文件、错用课程日期当申请期限 | 同样属于历史回放，不得假装系统已办理真实退费 |

**实际运行闭环**：读取用户选定公告/附件 → 列出版本和冲突 → 将明确要求转换成结构化条件，并保留原文定位 → 读取用户材料 → 用规则校验可确定的日期/身份/文件数量，用模型识别文件语义和跨文档矛盾 → 对缺失事实追问 → 用户补件 → 重新校验 → 生成规范文件名、清单、说明和 ZIP。用户自行检查并提交；MVP 不需要进入学校系统、获取学生账户密码或自动发送邮件。

“版本较新”不能独自决定正确性：学校转发时间、主办方发布日期、附件内修订号和具体授权关系分别保存。实质冲突无法判断时，输出待确认事项并阻止显示“可提交”，不能任选一条。

输出的术语用“资料齐备性检查通过”，不要称“申请获批”“满足全部资格”。现有 OCR 无法可靠确认所有签名真伪、印章或证明真实性；可检测缺失的占位状态，真实性需本人/经办方核验。

## 现场演示应该看到什么

1. 放入一份明显看似齐全的申请包：附件数量正确，但用了旧表格，身份分组也错误。
2. 系统指出具体出处和新旧差异，提出一到两个必要问题。
3. 用户补入缺件；Agent 调用文档处理、规则校验和打包工具，生成完整清单。
4. 临时加入一份更新通知或修改一项身份信息，系统撤销之前的通过状态，并只重检受影响要求。
5. 打开展示生成的包和核验轨迹，评委能追到原始文件页码/段落。

这个演示能展示记忆、工具使用、状态更新和结果验证。但自动生成 ZIP 本身很容易，真正要证明的是：新公告和真实材料下的错误识别与可靠修复。

## 数据和接口可达性

校内公开页面可以直接阅读，附件来自公开公告；用户证明材料需自愿提供，演示使用脱敏副本或明确标注的构造样本。不要把构造样本叫“真实办理成功案例”。当前未核实能够访问学生记录系统 API，也不需要该 API 完成原型。

若赛后扩展到庆南企业支持项目，**企业마당有官方开放 API**，提供 JSON/XML、地区标签、公告、申请期限、适用对象和附件字段。服务要求认证 key，使用申请表要求机构/企业名、姓名、邮箱、电话、系统名和 IP 或 URL；页面说明登记完成会显示 key 并发至邮箱。本次只核查了公开文档，没有申请 key、调用认证接口或确认具体配额。MVP 不应依赖当天一定获批。

官方接口说明：<https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi>

接口目录：<https://www.bizinfo.go.kr/apiList.do>

HWP 原样编辑和高保真填表是八天内的风险点。先限制为：读取 HWP/PDF、生成核验清单和材料包，并为支持的少量字段生成可人工复核的草稿。不要承诺任意 HWP 表格都能无损填写。

| 官方/产品来源 | 已核查事实 | 对选题的影响 |
|---|---|---|
| WelloBiz：<https://www.wellobiz.com/> | 官网列出公告 AI 摘要、机会提醒、日程管理、文件管理和专业人员辅导 | “自动找公告＋摘要＋提醒＋写计划书”已不稀缺。官网性能/节时数字是厂商宣称，本研究未独立验证 |

| BizNavi：<https://biznavi.ai.kr/> | 官网索引说明政府支持项目/事业计划书自动撰写、模拟面试等 | 不做生成长计划书的通用助手 |

本方案可争取的差异是 **新旧公告和真实用户证明之间的可复查核验、失败后补件和重新验证**。它依然不是全新科研问题；是否比现成工具更好，必须用同一资料和同一任务测试。产品官网没有列出某功能，不构成该产品绝对没有该功能的证据。

## 怎样用真实证据增强竞争力

建议正式开发期内完成以下小规模实验。所有数字为实验设计/建议目标，尚无实测结果。

**数据分开**：

- 真实使用组：8–12 名自愿学生，各做两个匹配难度的任务；记录实际用时和最终包是否有遗漏。旧申请是回放，当前申请是准备辅助，分别报告。
- 规则验证组：不少于 30 个脱敏/构造案例，覆盖缺件、错误身份分支、过期证据、来源冲突、未来生效规则、根本不符合资格、系统应追问但不应猜测等。明确标注哪些是构造的。
- 陌生公告组：留出至少一个没用于调整提示词/规则的流程或更新版本；避免只是记住本次竞赛材料。
- 两名人工标注者独立确定要求与错误；不一致的案例先解决争议，无法解决则标为不确定，不拿模型输出当真值。

**必须有的公平基线**：

1. 人工阅读官方页面＋现成翻译工具；给与系统同样的文件与时间条件。
2. 规则脚本/静态清单：相同结构化规则；对固定流程，它很可能更稳且便宜，应该承认。
3. 同款通用大模型：同样的公告和材料，允许其检查并生成清单；不能只给基线一条无背景短提示。
4. 完整 Agent；另做去掉版本核验或去掉最后验证的简单消融，衡量哪一环有实际作用。

**报告指标**：最终材料包正确率、关键缺漏召回率、无错材料被误报比例、错误地放行比例、正确追问/升级比例、任务用时中位数、每次成本和失败重试次数。小样本报告绝对人数和错误案例；不要只展示漂亮百分比，更不能说已经降低了行政退件率或签证风险。

建议的竞赛内接受条件：在留出集上的关键错误检出率不低于最强基线，最终包错误率明显下降；用户耗时同时下降。若只有速度提升而误放行增加，应先修复，不应宣称胜出。具体阈值在试运行后预先固定，再开展正式比较，避免看完结果后改门槛。

## 八天范围控制

- 第1天：选定3流程，冻结可执行规则和人工标注说明。
- 第2–3天：文档读入、引用定位、条件核验、缺件追问。
- 第4天：生成清单/打包、修复后重新核验、版本变化测试。
- 第5–6天：独立案例与真实学生对照测试，修复关键失误。
- 第7天：完成消融/失败统计、3分钟视频与报告。
- 第8天：复现检查和提交缓冲；不再增加流程。

赛前当前阶段可做资料和需求研究、联系自愿测试者和确认可用数据；参赛核心开发应遵守主办方正式开发期规定。没有取得合作承诺之前，不写“已在学校部署”或“与国际处合作”。

## 跨制造安全方向：为何不列为首选

确实有需求，也可提出“工人用母语复述操作要求 → AI发现遗漏/误解 → 分配针对性再培训 → 复测 → 主管审核”的理解检查 Agent。若能取得经专家确认的单项 SOP、实际外国工人和安全负责人，可对比直接翻译与闭环纠错后的关键步骤复述准确率。应在培训环境验证，不让 AI 自动发放作业许可或控制机器，也不能把复述正确等同于现实作业安全。

但目前没有这些数据/场地/专家承诺；照片隐患识别、风险文件生成、PTW和TBM已拥挤：

- Heinrich官网：<https://heinrich.dasancms.co.kr/> ，公开展示JSA、TBM、现场图像、工作许可等AI功能。
- Safe U Works官网：<https://www.safeuworks.com/대표도메인> ，公开展示风险评价、工作许可、TBM、电子审批等工作流。
- ez2AI Safety官网：<https://simbizkorea.com/en/safety> ，公开展示安全文档审查、图片风险分析、会议纪要与报告草稿。
- 大韩产业安全协会自身报道：<https://www.safety.or.kr/safety/bbs/BMSR00023/view.do?boardId=244932&menuNo=200120> ，已在外国工人培训中结合AI实时母语翻译和VR/视频。
- KOSHA公开资料入口：<https://smartsearch.kosha.or.kr/mobile> ，可以检索相关资料，但公开可读不代表任意教材都可不受限制再分发；使用具体材料时查对应许可。没有核验到可直接下载、带可信“理解与误解”标签的本地工人公开数据集。

因此只有拿到真实专家和目标用户后才值得转向这一选题。否则校园核验Agent更易做出诚实、可复现的真实效果证据。

## 尚未确认的事项

- 用户队伍人数、擅长的技术、可访谈同学/行政人员人数。
- 测试者是否愿意提供脱敏材料以及指导/复核人员是否可参与。
- 校内流程的通用性：当前两项来源是建工系转发，不等同于用户所在专业适用的全部细则。
- 任一竞品的真实内部技术、错误率或全量能力；只核查公开产品说明。
- 新版评分权重、竞争参赛队伍和现场评委偏好。

本次研究没有联系任何学校、企业或个人，没有注册接口、提交申请、进入受限校务系统或实现参赛代码。
